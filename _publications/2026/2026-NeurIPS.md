abstract: >-
  We introduce TokenProbe, a diagnostic and optimization framework for efficient LLM reasoning based on token value inequality. Normalized token-level log probabilities distinguish core reasoning tokens from redundant exploration. An efficient GRPO objective selectively compresses redundant tokens, reducing token usage by 76% while preserving reasoning quality. Under matched reasoning-length budgets, TokenProbe can outperform strong flagship baselines such as Gemini-3.1-Pro.
